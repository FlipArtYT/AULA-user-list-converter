# 👤 AULA-user-list-converter
A CLI tool to convert iServ user list CSVs to AULA user list CSVs

## 🖥️ Usage
```
usage: main.py [-h] [-v] [-i INPUT_PATH] [-o OUTPUT_PATH]

Convert iServ user list CSVs to AULA user list CSVs

options:
  -h, --help            show this help message and exit
  -v, --version         show program's version number and exit
  -i INPUT_PATH, --input-path INPUT_PATH
                        Path to the input the CSV file
  -o OUTPUT_PATH, --output-path OUTPUT_PATH
                        Path to the output the CSV file
```
